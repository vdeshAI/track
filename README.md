# Stakeholder Outreach Intelligence (Streamlit)

## Files
- `app.py` — Streamlit dashboard
- `stakeholder_outreach_intelligence_system.xlsx` — workbook backing the app
- `requirements.txt` — Python dependencies

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Notes
- Data date: 2026-04-15
- The workbook only includes clearly public or self-published direct contact details.
- Many journalists do not publish direct phone numbers; blanks mean not publicly listed.
